Logo assets live here.

Client logos:
- Put customer/company logos in `clients/` using the file names declared in `src/data/logoAssets.js`.
- Example: `clients/vnpt.png`, `clients/fpt.png`, `clients/kiotviet.png`.

AI model logos:
- Put AI/provider logos in `models/` using the file names declared in `src/data/logoAssets.js`.
- Example: `models/openai.png`, `models/claude.png`, `models/gemini.png`.

Supported formats can be PNG, SVG, JPG, or WEBP, but if you change the extension, update `src/data/logoAssets.js`.
